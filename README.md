
# 🗺️ Pop-Course (팝코스)

지도 기반 팝업스토어 & 핫플 큐레이션 웹 서비스 (초보자 주도적 바이브 코딩 프로젝트)

## 📌 프로젝트 소개

카카오 지도 API를 활용해 성수, 홍대 등의 팝업스토어와 축제, 핫플레이스 정보를 한눈에 보고 필터링할 수 있는 B2C 웹 서비스입니다.

## 🎯 최종 목표

Pop-Course는 개인 포트폴리오 제작을 기반으로 지도 기반 B2C/B2B 서비스의 사용자 경험을 구현하는 프로젝트입니다. 장소를 단순히 보여주는 데서 끝나지 않고, 예상 혼잡도와 교통 편의, 이동 접근성 정보를 제공해 사용자가 방문 여부와 이동 방법을 쉽게 판단하도록 돕습니다.

장기적인 기능 방향과 개발 판단 기준은 [PROJECT_GOALS.md](PROJECT_GOALS.md)에 정리했습니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, Vanilla JS (Kakao Map API)
- **Backend**: Python (FastAPI), Supabase (PostgreSQL)
- **Data/AI**: Naver Search API (블로그 후기 수집)
- **Deployment**: Vercel
