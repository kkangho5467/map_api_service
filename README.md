
# 🗺️ Pop-Course (팝코스)

지도 기반 팝업스토어 & 핫플 큐레이션 웹 서비스 (초보자 주도적 바이브 코딩 프로젝트)

## 📌 프로젝트 소개

카카오 지도 API를 활용해 성수, 홍대 등의 팝업스토어와 축제, 핫플레이스 정보를 한눈에 보고 필터링할 수 있는 B2C 웹 서비스입니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, Vanilla JS (Kakao Map API)
- **Backend**: Python (FastAPI), Supabase (PostgreSQL)
- **Data/AI**: Naver Search API (블로그 후기 수집)
- **Deployment**: Vercel
