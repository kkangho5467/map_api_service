# Pop-Pin 기능 설명 노트

> 기능 하나를 완성할 때마다 1장씩 쌓는 **"어떻게 만들었는지" 설명서**입니다.
> 발표·면접·포트폴리오에서 각 노트의 **"이렇게 설명하세요"** 칸을 그대로 읽으면 됩니다.

## 목차

| 번호 | 기능 | 한 줄 요약 | 완성일 |
|---|---|---|---|
| 01 | [카카오 로그인](01_카카오로그인.md) | 카카오 계정으로 로그인, 새로고침해도 유지 | 2026-09-26 |
| 02 | [마이페이지 · 커플 연결](02_마이페이지_커플연결.md) | 프로필 수정, 초대 코드로 커플 연결, D+N | 2026-09-26 |
| 03 | [장소 데이터 · 카테고리 마커](03_장소데이터_마커.md) | 행궁동 실제 장소 41곳, 카테고리별 핀 | 2026-09-26 |
| 04 | [초대 수락 · 실시간 알림](04_초대수락.md) | 요청 → 수락해야 커플 성립, 새로고침 없이 반영 | 2026-09-28 |
| 05 | [개인 찜](05_개인찜.md) | 상세 모달 ♡로 찜, '찜한 곳' 필터로 모아 보기 | 2026-09-28 |

> 참고: 01~03은 스킬·MCP를 세팅하기(2026-09-28) **전에** 만든 기능이라, "사용한 도구"에 스킬 대신 직접 쓴 서비스를 적었습니다.

## 프로젝트 전체 구조 (한 장 요약)

```
[사용자 휴대폰 브라우저]
   React 화면 (Vite로 빌드, Vercel에 배포)
      │  카카오맵 JS SDK ── 지도·마커 표시
      │
      ▼  supabase-js (공개 anon 키)
[Supabase]
   Auth ── 카카오 로그인 대행
   DB(Postgres) ── places / profiles / couples …  ← RLS가 "누가 어떤 행을 볼 수 있는지" 검사
   Storage ── 프로필 사진
```
