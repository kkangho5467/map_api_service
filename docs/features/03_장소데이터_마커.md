# 03. 장소 데이터 · 카테고리 마커

> 완성일: 2026-09-26 · 관련 파일: `scripts/fetch-kakao-places.mjs`, `supabase/03_seed_haenggung_places.sql`,
> `src/components/MapView.jsx`, `src/lib/placeInfo.js`

## 왜 만들었나
샘플 3곳으로는 추천할 수 없어서, 데이트 코스 첫 지역으로 **수원 행궁동**의 실제 장소를 모았습니다.

## 어떻게 동작하나
```
[내 컴퓨터] 스크립트 실행 ──▶ 카카오 로컬 API(행궁동 반경 1km 검색)
          ──▶ SQL 파일 자동 생성 ──▶ 내용 확인 후 Supabase에서 실행 ──▶ places 41곳
[앱] places 조회 ──▶ 카테고리별 핀 마커 (맛집 주황 · 카페 브라운 · 명소 하늘색)
```
- 카페·맛집은 키워드와 카테고리 코드로 검색하고, 명소 9곳은 이름으로 정확히 찾았습니다.
- 카카오 장소 ID를 `unique`로 걸어서 **SQL을 두 번 실행해도 중복이 생기지 않습니다.**
- 카테고리는 `restaurant` / `cafe` / `spot` 3개로 제한합니다(DB의 check 제약).
- 길찾기 버튼은 카카오 장소 상세 페이지(`place_url`)로 연결됩니다.

## 핵심 개념
| 용어 | 쉬운 뜻 |
|---|---|
| REST API 키 | 서버·내 컴퓨터에서만 쓰는 비밀 키. 브라우저에 노출되면 안 됨 |
| `VITE_` 접두사 | 이게 붙은 환경변수만 브라우저 코드에 들어감 → 비밀 키에는 **붙이지 않음** |
| 시드(seed) 데이터 | 앱이 처음 쓸 기본 데이터를 DB에 채워 넣는 것 |
| unique / check 제약 | DB가 "중복 금지", "이 값만 허용"을 스스로 지키게 하는 규칙 |

## 사용한 도구
| 도구 | 종류 | 왜 썼나 |
|---|---|---|
| 카카오 로컬 API | 외부 서비스 | 실제 장소 이름·좌표·주소 수집 |
| Node.js 스크립트 | 직접 작성 | 비밀 키를 브라우저 밖(내 컴퓨터)에서만 쓰기 위해 |
| 카카오맵 JS SDK | 외부 서비스 | 지도와 커스텀 마커 표시 |

## 이렇게 설명하세요
> "카카오 로컬 API로 행궁동 반경 1km의 실제 장소를 수집해, 카페·맛집·명소 41곳을 DB에 넣었습니다. 비밀 API 키는 브라우저가 아닌 로컬 스크립트에서만 쓰고, 결과를 SQL 파일로 만들어 검토한 뒤 반영했습니다. 카카오 장소 ID에 중복 금지 규칙을 걸어 여러 번 실행해도 데이터가 안전하고, 지도에서는 카테고리별 색상 핀으로 구분됩니다."
